# CleverGolem

A golem that's clever.

## About

CleverGolem is built from ancient materials and modern wit. Unlike your average golem — lumbering, single-minded, easily fooled by riddles — CleverGolem thinks before it acts.

## Features

- 🧱 Made of stone, runs on smarts
- 🧠 Clever (see name)
- 💬 Won't fall for the same trick twice
