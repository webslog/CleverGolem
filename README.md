# CleverGolem

A training repository for learning Git basics.

## About

CleverGolem is a sandbox for practicing Git fundamentals — committing, branching, merging, pushing, and everything in between. Break things, try things, learn things.

## What I'm Learning

- [X] Initializing a repo (`git init`) 
- [ ] Staging and committing (`git add`, `git commit`)
- [ ] Connecting to a remote (`git remote`, `git push`)
- [ ] Branching and merging (`git branch`, `git merge`)
- [ ] Pulling changes (`git pull`)
- [ ] Reading history (`git log`, `git status`, `git diff`)

## Useful Commands

| Command | What it does |
|--------|--------------|
| `git status` | Show what's changed |
| `git log --oneline` | See commit history |
| `git checkout -b <branch>` | Create and switch to a new branch |
| `git merge <branch>` | Merge a branch into the current one |
| `git pull origin main` | Pull latest changes from GitHub |
